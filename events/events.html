EventSphere Privacy

EventSphere is a demonstration website developed as part of the Web Design and Client Side Scripting CA2 Group Project.

Information entered into demonstration forms, including names, email addresses and optional phone numbers, is used only within the current browser session to demonstrate website functionality.

EventSphere does not store this information in a database or use it for real ticket purchases, payments or event admissions.

Any booking references, confirmations and tickets generated by EventSphere are demonstration data only.

EventSphere Terms & Conditions

EventSphere is an educational demonstration website created for the Web Design and Client Side Scripting CA2 Group Project.

Event information, ticket prices, booking references and availability shown on this website are provided for demonstration purposes only.

EventSphere does not process real payments, complete real bookings or provide admission to any event.

Tickets generated by EventSphere are facsimile demonstration tickets only and are clearly marked as not valid for admission.

By using this demonstration website, users acknowledge that all bookings, transactions and tickets are simulated as part of the CA2 project.

EventSphere Cookies

EventSphere is an educational demonstration website developed for the Web Design and Client Side Scripting CA2 Group Project.

EventSphere does not currently use advertising, analytics or tracking cookies.

The demonstration booking process operates within the current browser session and does not use cookies to store customer details, booking information or payment information.

If cookies or similar technologies were added to a future version of EventSphere, visitors would be informed about their purpose before non-essential cookies were used.

The current EventSphere CA2 website therefore does not require visitors to accept non-essential cookies.

About EventSphere

EventSphere is a demonstration event discovery and ticket-booking website designed to make finding and exploring events simple and engaging.

The website brings event information, ticket selection, booking support and customer help together in one consistent experience.

Visitors can explore events, review event information, select demonstration tickets, calculate booking costs and move through a multi-step booking process.

EventSphere has been designed with responsive layouts, accessibility and clear navigation in mind so that the experience remains usable across desktop, tablet and mobile devices.

CA2 Group Project

EventSphere is being developed as the Continuous Assessment 2 group project for Web Design and Client Side Scripting (HDCAIMLFE) .

The project is being completed by Group 3 and demonstrates the use of HTML5, CSS, Bootstrap 5.3 and client-side JavaScript.

The website includes responsive page layouts, interactive event and ticket features, form validation, accessibility considerations and a simulated ticket-booking experience.

Some event information, ticket data, booking references and generated tickets are fictional and are included solely to demonstrate the functionality of the website.

All tickets generated by EventSphere are facsimiles and are not valid for admission to any real event.
